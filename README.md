# Анализ каталога игр Steam

Практическая работа по хранению и обработке данных. Проект собирает сведения об играх из каталога Steam, сохраняет их в SQLite и выполняет агрегирующие SQL-запросы с помощью SQLAlchemy и pandas.

## Что собирается

Парсер получает из карточек каталога Steam следующие данные:

- идентификатор приложения и название игры;
- дату выхода в формате `дд.мм.гггг`;
- текущую цену в евро, включая цену после скидки;
- процент скидки;
- долю положительных отзывов в процентах;
- поддерживаемые платформы: Windows, macOS и Linux.


## Структура проекта

- `test_scraper.py` — сбор и очистка данных Steam; сохраняет результат в `raw_games.json`.
- `load_json.py` — загрузка JSON в SQLite. При повторной загрузке существующие записи обновляются по `app_id`, новые добавляются.
- `db.py` — описание таблицы `games` и инициализация базы данных.
- `python_aggregator.py` — пять агрегирующих запросов и вывод результатов в pandas DataFrame.
- `requirements.txt` — список необходимых Python-библиотек.

## Установка

Требуется Python 3.10 или новее.

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

В Windows для активации используйте:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Запускайте команды из корневой папки проекта.

1. Соберите данные и создайте `raw_games.json`:

   ```bash
   python test_scraper.py
   ```

   Скрипт запрашивает каталог с целевым лимитом до 3000 игр. Фактическое число записей может быть меньше, если каталог вернул меньше карточек.

2. Загрузите данные в SQLite:

   ```bash
   python load_json.py
   ```

   При первом запуске будет создан файл `steam.db` и таблица `games`. При последующих запусках строки с тем же `app_id` обновляются, поэтому повторная загрузка не создаёт их копии.

3. Выполните агрегирующие запросы:

   ```bash
   python python_aggregator.py
   ```

   Результаты выводятся отдельно для каждой сводки. Среди них — средняя цена по году выпуска, статистика по сочетаниям платформ, скидкам, диапазонам рейтинга и цены.

## Таблица `games`

| Поле | Назначение |
| --- | --- |
| `app_id` | Идентификатор приложения Steam, первичный ключ |
| `title` | Название игры |
| `release_date` | Дата выхода в формате `дд.мм.гггг` |
| `price` | Текущая цена в евро; для игр со скидкой — цена после скидки |
| `discount` | Скидка в процентах |
| `rating` | Доля положительных отзывов в процентах |
| `platforms` | Поддерживаемые платформы одной строкой |

База данных создаётся в `steam.db` в текущей папке запуска. Для просмотра таблиц и записей можно использовать DB Browser for SQLite.
